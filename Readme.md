3rd Years — HomeHub (Smart Property Rental Platform)
Story: Finding the right rental property is often a frustrating experience. Tenants struggle to compare properties, negotiate rental prices, and communicate with property owners, while landlords have difficulty managing inquiries and showcasing their properties efficiently.
Your challenge is to design and develop a Property Rental Platform that bridges this gap by providing a seamless experience for both property owners and prospective tenants. The platform should support two different user roles, each with its own set of features and responsibilities.
Roles: Property Owner and Tenant — unchanged responsibilities, but with explicit mechanics now required:

1. Property Owner (Landlord)
The Property Owner should be able to:
Register and log in.
Add new rental properties.
Update or remove property listings.
Upload property details, pricing, images, and available amenities.
Receive and respond to rental inquiries.
Review and negotiate rental offers from interested tenants.

3. Tenant
The Tenant should be able to:
Register and log in.
Browse available rental properties.
View detailed property information.
Search and filter properties based on preferences.
Express interest in a property.
Negotiate the rental price directly within the application.
Ask questions regarding amenities, maintenance, availability, or other property-related information using the in-app communication system.
Track the status of ongoing conversations and negotiations.


Expected Features:
Secure authentication for both user roles.(Better auth,clerk)
Responsive and intuitive user interface.
Property listing and detailed property pages , live location of the property.
In-app messaging or chat between tenants and property owners for the Negotiations.
Price negotiation workflow.
Property search and filtering.
Professional dashboard for both tenants and property owners.
Amenity questions and price negotiation share one threaded conversation per property-per-tenant
Both dashboards show live, data-derived counts ("2 pending offers," "1 awaiting your response") — not hardcoded.
